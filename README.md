## Problema y objetivo

Los estudiantes universitarios reciben demasiada información de diferentes tipos de
canales, como por ejemplo; instagram, whatsapp o facebook. El problema con esta
situación es que los estudiantes no pueden separar la información que realmente les
interesa de la información que pueden considerar como spam, esto afecta a todos los
universitarios y tiene consecuencia directa en la escuela cuando por ejemplo; no
saben las fechas de trámites importantes. Actualmente no existe una solución para
curar la información como quisiéramos, existen grupos generacionales
específicamente para compartir anuncios, sin embargo, también sufren del problema
de contener spam, el alumno es el que debería escoger cual es el tipo de información
que quiere recibir. Al presentar una solución a este problema, el estudiante tendrá
una vida estudiantil más fluida, sin tener incertidumbre acerca de trámites, becas o
eventos.

Desarrollar e implementar una plataforma
web de difusión para estudiantes universitarios, que permita filtrar y centralizar la
información relevante con el fin de optimizar el acceso a avisos académicos y
administrativos.
